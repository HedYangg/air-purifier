# การทำงานของ Sensor Node, Gateway Node และ Actuator

ในโปรเจกต์เครื่องฟอกอากาศของเรา **Sensor Node วัดค่า → Gateway รับข้อมูลและแปลท่ามือ → Actuator เปิดหรือปิดพัดลม** โดย ESP32 เป็นตัวตัดสินใจขั้นสุดท้ายว่าจะสั่งพัดลมหรือไม่

| ส่วน | อุปกรณ์ | ทำหน้าที่อะไร |
|---|---|---|
| **Sensor Node** | ESP32-S3 + PMS5003, MQ-135, MPU6050 | อ่านค่า **PM2.5**, การตอบสนองต่อก๊าซในหน่วย **mV** และมุมเอียงสองแกน แล้วส่งข้อมูลไป Raspberry Pi ผ่าน **MQTT** |
| **Gateway Node** | Raspberry Pi 5 + กล้อง + KY-015 | อ่านอุณหภูมิและความชื้น ใช้ **MediaPipe** ตรวจท่ามือ และส่งคำสั่งเปิดหรือปิดโหมดทำงานกลับไปที่ ESP32 ผ่าน MQTT นอกจากนี้ยังแสดงข้อมูลบนแดชบอร์ดและเก็บค่าย้อนหลังใน **Prometheus** บน Pi |
| **Actuator** | พัดลม ควบคุมผ่านรีเลย์ KY-019 | ESP32 สั่งรีเลย์ให้จ่ายหรือตัดไฟพัดลม ตัวพัดลมคืออุปกรณ์ที่ลงมือทำงานจริง |

**ตัวอย่างตอนใช้งาน** แบมือค้าง **3 วินาที** เพื่อเปิดโหมดทำงาน จากนั้นพัดลมจะหมุนเมื่อ **PM2.5 มากกว่า 20 µg/m³** และ **Safety Lock เคลียร์** ถ้า PM2.5 ลดลงเหลือ 20 หรือต่ำกว่า มุมเอียงแกนใดแกนหนึ่งออกนอกช่วง **70°–130°** หรือกำมือค้าง **3 วินาที** พัดลมจะหยุด

จุดสำคัญคือ **Pi ส่งคำสั่งเปิดโหมด ส่วน ESP32 ตรวจเงื่อนไขและสั่งรีเลย์เอง** ดังนั้นแบมือแล้วเครื่องเปิดโหมดได้แม้ค่า PM2.5 จะต่ำ แต่พัดลมจะรอจนค่าฝุ่นเกินเกณฑ์
